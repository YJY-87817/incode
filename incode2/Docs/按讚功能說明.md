# Content 按讚功能完整說明

## ?? 功能概述

按讚功能允許已登入的使用者對貼文進行互動（如：按讚、收藏、封鎖等）。系統採用 **Toggle** 設計，同一個互動按一次新增，再按一次移除。

---

- **DTO**: 
  - `incode2\Dtos\ContentInteraction\CreateContentInteractionDto.cs`
  - `incode2\Dtos\ContentInteraction\ContentInteractionDto.cs`

### 互動分類（InteractionCategory）
根據資料庫設計，互動分類包括：
- **1**: Like（按讚）
- **2**: Dislike（不讚同）
- **3**: Block（封鎖）
- **4**: Bookmark（收藏）

## ?? API 端點

### 1. **按讚/互動 (新增或移除)**
```
POST /api/contentinteractionapi
```

**請求頭（Headers）**
```
Authorization: Bearer <token> （必須）
Content-Type: application/json
```

**請求體（Request Body）**
```json
{
  "interactionCategoryId": 1,  // 互動類型 ID（1=讚，2=不讚，3=封鎖，4=收藏）
  "contentId": 5                 // 貼文 ID
}
```

**回應 - 新增互動**
```json
{
  "message": "互動已新增或更新",
  "isRemoved": false,
  "data": {
    "contentInteractionId": 123,
    "interactionCategoryId": 1,
    "interactionCategoryName": "Like",
    "contentId": 5,
    "userId": 10,
    "createdAt": "2024-01-15T10:30:00"
  }
}
```

**回應 - 移除互動（再按一次）**
```json
{
  "message": "互動已移除",
  "isRemoved": true,
  "data": null
}
```

## ?? 安全性

### 授權要求
- ? **POST（新增/更新互動）** - 必須授權，自動使用當前使用者 ID
- ? **GET（查詢互動）** - 無需授權（公開資訊）
- ? **DELETE（刪除互動）** - 無需授權

### 特點
- 使用者無法在 POST 請求中指定 `userId`，系統會從 Token 中自動取得
- 確保使用者只能互動自己的操作

## ?? 前端使用範例（Vue.js/JavaScript）

### 按讚功能
```javascript
// 引入 axios
import axios from 'axios';

const api = axios.create({
  baseURL: 'http://localhost:7190/api',
  withCredentials: true, // 允許帶 Cookie
  timeout: 300000 // 5 分鐘超時
});

// 按讚/移除讚
async function toggleLike(contentId) {
  try {
    const response = await api.post('/contentinteractionapi', {
      interactionCategoryId: 1, // Like ID
      contentId: contentId
    });

    if (response.data.isRemoved) {
      console.log('已取消讚');
    } else {
      console.log('已按讚');
    }

    return response.data;
  } catch (error) {
    console.error('按讚失敗:', error.response?.data || error.message);
  }
}

// 查詢互動統計
async function getInteractionStats(contentId) {
  try {
    const response = await api.get(`/contentinteractionapi/stats/${contentId}`);
    console.log('互動統計:', response.data);
    return response.data;
  } catch (error) {
    console.error('查詢失敗:', error);
  }
}

// 查詢使用者是否已按讚
async function checkUserLike(contentId) {
  try {
    const response = await api.get(`/contentinteractionapi/user/${contentId}`, {
      params: { userId: currentUserId }
    });
    
    // 如果有回傳資料，表示已按讚
    if (response.data.interactionCategoryId) {
      console.log('已按讚');
      return true;
    } else {
      console.log('未按讚');
      return false;
    }
  } catch (error) {
    console.error('查詢失敗:', error);
    return false;
  }
}
```

```javascript

  <div>

      @click="toggleLike(contentId)"
      :class="{ liked: isLiked }"

    </button>

  baseURL: 'http://localhost:7190/api',
  withCredentials: true,
  timeout: 300000
});

// 初始化 - 檢查使用者是否已按讚
const checkLikeStatus = async () => {
  try {
    const response = await api.get(`/contentinteractionapi/user/${contentId.value}`, {
      params: { userId: getCurrentUserId() }
    });
    
    isLiked.value = !!response.data.contentInteractionId;
  } catch (error) {
    console.log('查詢按讚狀態失敗');
  }
};

// 取得按讚數量
const fetchLikeCount = async () => {
  try {
    const response = await api.get(`/contentinteractionapi/stats/${contentId.value}`);
    const likeStats = response.data.interactionStats.find(s => s.interactionType === 'Like');
    likeCount.value = likeStats?.count || 0;
  } catch (error) {
    console.error('取得按讚數失敗:', error);
  }
};

// 切換按讚狀態
const toggleLike = async (cId) => {
  try {
    const response = await api.post('/contentinteractionapi', {
      interactionCategoryId: 1,
      contentId: cId
    });

    isLiked.value = !response.data.isRemoved;
    
    // 重新取得統計數字
    await fetchLikeCount();
  } catch (error) {
    console.error('按讚失敗:', error.response?.data || error.message);
  }
};

onMounted(async () => {
  await checkLikeStatus();
  await fetchLikeCount();
});
</script>
```

## ??? 後端實現細節

### ContentInteractionService.AddOrUpdateInteraction
該方法實現 Toggle 邏輯：

1. **檢查內容是否存在**
   ```csharp
   var contentExists = await _context.Content.AnyAsync(c => c.ContentId == dto.ContentId);
   ```

2. **查找現有互動**
   ```csharp
   var existingInteraction = await _context.ContentInteraction
     .FirstOrDefaultAsync(ci => ci.ContentId == dto.ContentId && ci.UserId == dto.UserId);
   ```

3. **判斷操作**
   - 如果存在 **相同的互動類型** → **刪除**（取消讚）
   - 如果存在 **不同的互動類型** → **更新**（改為其他互動）
   - 如果 **不存在** → **新增**（新讚）

## ?? 常見問題

### Q1: 如何驗證使用者已登入？
在前端調用 API 前檢查 Token 是否存在：
```javascript
const token = localStorage.getItem('token');
if (!token) {
  // 導向登入頁面
  window.location.href = '/login';
}
```

### Q2: 互動分類 ID 在哪裡查詢？
調用 `GET /api/contentinteractionapi/categories` 端點取得所有分類。

### Q3: 如何同時顯示多種互動（讚、不讚、收藏）？
調用統計端點 `GET /api/contentinteractionapi/stats/{contentId}` 並按分類名稱篩選。

### Q4: 使用者可以同時有多個互動嗎？
**不行**。同一使用者對同一貼文只能有一個互動。若要改為其他互動，會自動更新。

## ?? 資料庫設計

### ContentInteraction 表
```sql
CREATE TABLE content_interaction (
  content_interaction_id INT PRIMARY KEY IDENTITY(1,1),
  category_id INT NOT NULL FOREIGN KEY REFERENCES interaction_category,
  content_id INT NOT NULL FOREIGN KEY REFERENCES content,
  user_id INT NOT NULL FOREIGN KEY REFERENCES [user],
  created_at DATETIME DEFAULT GETDATE(),
  updated_at DATETIME DEFAULT GETDATE()
);
```

### InteractionCategory 表
```sql
CREATE TABLE interaction_category (
  interaction_category_id INT PRIMARY KEY IDENTITY(1,1),
  name NVARCHAR(100) NOT NULL,
  description NVARCHAR(200),
  is_active INT NOT NULL,
  created_at DATETIME DEFAULT GETDATE(),
  updated_at DATETIME DEFAULT GETDATE()
);
```
