# 按讚功能 API 測試指南

使用 Postman 或 curl 測試按讚功能的完整步驟。

---

## ?? 前置準備

1. **確保後端運行**
   ```
   http://localhost:7190
   ```

2. **獲取 Token（登入）**
   - 先調用登入 API 獲取驗證 Token
   - Token 放在 Authorization header 中

3. **準備測試數據**
   - 確認資料庫中存在有效的 Content ID
   - 確認互動分類已存在（通常系統初始化時已建立）

---

## ?? 測試場景

### 場景 1: 新增按讚

**步驟 1** - 檢查互動分類
```
GET /api/contentinteractionapi/categories
Authorization: Bearer <your_token>
```

**預期回應：**
```json
[
  {
    "interactionCategoryId": 1,
    "name": "Like",
    "description": "按讚",
    "isActive": 1
  }
]
```

**步驟 2** - 檢查使用者目前是否已按讚
```
GET /api/contentinteractionapi/user/5?userId=10
Authorization: Bearer <your_token>
```

**預期回應（未按讚）：**
```json
{
  "message": "此使用者尚未對該內容進行互動"
}
```

**步驟 3** - 新增按讚
```
POST /api/contentinteractionapi
Authorization: Bearer <your_token>
Content-Type: application/json

{
  "interactionCategoryId": 1,
  "contentId": 5
}
```

**預期回應：**
```json
{
  "message": "互動已新增或更新",
  "isRemoved": false,
  "data": {
    "contentInteractionId": 123,
    "interactionCategoryId": 1,
    "interactionCategoryName": "Like",
    "contentId": 5,
    "userId": 10,
    "createdAt": "2024-01-15T10:30:00"
  }
}
```

? **驗證：** contentInteractionId 應該有值且 isRemoved = false

---

### 場景 2: 取消按讚

**步驟 1** - 再次調用新增按讚（同樣的 contentId 和 interactionCategoryId）
```
POST /api/contentinteractionapi
Authorization: Bearer <your_token>
Content-Type: application/json

{
  "interactionCategoryId": 1,
  "contentId": 5
}
```

**預期回應（取消讚）：**
```json
{
  "message": "互動已移除",
  "isRemoved": true,
  "data": null
}
```

? **驗證：** isRemoved = true，data = null

**步驟 2** - 驗證讚已移除
```
GET /api/contentinteractionapi/user/5?userId=10
Authorization: Bearer <your_token>
```

**預期回應：**
```json
{
  "message": "此使用者尚未對該內容進行互動"
}
```

---

### 場景 3: 改變互動類型

**步驟 1** - 使用者先按讚
```
POST /api/contentinteractionapi
Authorization: Bearer <your_token>
Content-Type: application/json

{
  "interactionCategoryId": 1,
  "contentId": 5
}
```

**預期回應：** isRemoved = false

**步驟 2** - 改為收藏（interactionCategoryId = 4）
```
POST /api/contentinteractionapi
Authorization: Bearer <your_token>
Content-Type: application/json

{
  "interactionCategoryId": 4,
  "contentId": 5
}
```

**預期回應：**
```json
{
  "message": "互動已新增或更新",
  "isRemoved": false,
  "data": {
    "interactionCategoryId": 4,
    "interactionCategoryName": "Bookmark"
  }
}
```

? **驗證：** interactionCategoryId 應該變成 4（Bookmark）

---

### 場景 6: 錯誤情況 - 未授權

```
POST /api/contentinteractionapi

{
  "interactionCategoryId": 1,
  "contentId": 5
}
```

**預期回應：** 401 Unauthorized
```json
{
  "message": "無法取得使用者ID"
}
```

? **驗證：** 沒有 Token 應該被拒絕

### 使用步驟
1. 在 Postman 中設置環境變數 `token` 為你的驗證 token
2. 設置 `baseUrl` 為你的後端地址
3. 依序運行測試

## ?? 除錯建議

### 如果出現 401 Unauthorized
- ? 確保 Token 有效
- ? 確保 Token 格式正確：`Authorization: Bearer <token>`
- ? 檢查 Token 是否過期

### 如果出現 400 Bad Request
- ? 確保 Request Body 格式正確
- ? contentId 和 interactionCategoryId 都必須 > 0
- ? ContentType 設置為 `application/json`

### 如果出現 500 Internal Server Error
- ? 檢查 contentId 是否存在
- ? 檢查 interactionCategoryId 是否存在
- ? 在後端 Output 窗口查看詳細錯誤

### 使用 curl 測試

**新增按讚：**
```bash
curl -X POST http://localhost:7190/api/contentinteractionapi \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "interactionCategoryId": 1,
    "contentId": 5
  }'
```

**查詢統計：**
```bash
curl -X GET http://localhost:7190/api/contentinteractionapi/stats/5 \
  -H "Authorization: Bearer <token>"
```
